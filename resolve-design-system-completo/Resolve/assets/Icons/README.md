# Icons

Lucide (ISC), 24×24, traço 1.75, pontas arredondadas, tinta fixa `#111213` (`ink`) — um SVG em `<img>` não herda cor; para recolorir use o componente `Icon`, que desenha em `currentColor`.

- Categorias: `wrench` (serviços em geral, encanador), `zap` (elétrica), `droplets` (hidráulica — substituto do cano do mockup), `laptop` (informática), `armchair` (montagem), `hammer` (montagem de móveis).
- Interface: `search`, `map-pin`, `chevron-right`, `arrow-left`, `arrow-right`, `heart`, `share`, `star`, `check`, `shield-check`.
- Abas e pessoas: `house`, `heart`, `message-circle`, `user`, `user-round` (avatar sem foto).
