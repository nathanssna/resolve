# Rating

Nota com estrela: estrela `star`, nota em negrito `ink`, contagem entre parênteses em `ink-muted`. Props: `value` (número; a vírgula decimal é automática), `count`, `suffix` (ex.: "avaliações"), `size` da estrela.

- A estrela amarela não tem contraste 3:1 sobre branco; por isso a nota numérica nunca é omitida.
