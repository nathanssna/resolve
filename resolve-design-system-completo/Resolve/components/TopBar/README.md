# TopBar

Barra superior de 52px com voltar. Props: `title` (opcional, `title-md`), `onBack` (passe `false` para esconder a seta), `backHref` (link de volta), `actions` (lista de `{icon, label, onClick, href, filled}`; `filled` preenche o ícone com `brand`, ex.: favoritado).

- Sem título nas telas de detalhe; ações à direita (favoritar, compartilhar).
- Todo botão de ícone recebe `label` para leitores de tela.
