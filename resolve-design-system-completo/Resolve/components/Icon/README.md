# Icon

Ícone de linha 24px, traço 1.75, sempre em `currentColor`. Props: `name` (um de `Resolve.iconNames`), `size`, `strokeWidth`, `fill` (use `"currentColor"` para a estrela e o pin), `label` (só quando o ícone está sozinho e carrega sentido).

- Use o traço 1.75 em tudo; 2 em chevrons e setas pequenas.
- O conjunto é Lucide (ISC). Para um ícone novo, pegue o mesmo nome no Lucide e acrescente ao bundle.
