# Button

Botão em pílula de 48px, rótulo `label-lg`. Props: `variant` (`"primary"` amarelo, `"dark"` preto, `"link"` sublinhado), `block` (largura total), `iconRight` (nome de ícone), `href` (vira um link `<a>` com a mesma aparência — use para navegar), `onClick` e os atributos de `<button>`.

- **primary** (`brand` + `on-brand`): a ação principal de uma tela de conteúdo — "Solicitar serviço". Uma por tela.
- **dark** (`ink` + `on-ink`): ação principal sobre fundo `brand`, onde o amarelo sumiria — "Começar" na boas-vindas.
- **link**: ação secundária em texto — "Entrar".
- Verbo no infinitivo, primeira letra maiúscula, sem ponto.
