# ProfessionalCard

Card da lista de profissionais: avatar, nome, nota, distância, função | experiência e tags. Props: `name`, `rating`, `count`, `distance`, `role`, `experience`, `tags` (array), `avatar` (url), `href` (link para o perfil) ou `onClick`.

- Distância sempre como "2,3 km de você" (vírgula decimal).
- A ordem segue o chip de filtro ativo.
