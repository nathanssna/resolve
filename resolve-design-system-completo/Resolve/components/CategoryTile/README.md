# CategoryTile

Atalho de categoria: bloco 56px `surface-muted` com raio `radius-lg` e rótulo `caption` abaixo. Props: `icon`, `label`, `active`, `onClick`.

- Só uma ativa por vez; a ativa vira `brand`.
- Rótulo em até duas linhas ("Serviços em geral").
