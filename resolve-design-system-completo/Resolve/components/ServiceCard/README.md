# ServiceCard

Linha da lista "Serviços em destaque": bloco de ícone 56px, título, subtítulo, nota e chevron. Props: `icon`, `title`, `subtitle`, `rating`, `count`, `href` (o card vira link para o detalhe) ou `onClick`.

- Card inteiro é clicável e leva ao detalhe do serviço.
- Subtítulo curto, em minúsculas depois da primeira palavra, sem ponto.
- Empilhe com `space-3` entre cards.
